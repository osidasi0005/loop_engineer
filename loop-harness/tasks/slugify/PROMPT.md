# タスク仕様: slugify 関数の実装

`src/slugify.mjs` に、文字列を URL スラッグへ変換する `slugify(text)` を named export で実装する。

## 完了条件（すべて満たすこと）

1. `node --test "test/**/*.test.mjs"` がすべて PASS する
2. 依存パッケージを追加しない（Node 標準機能のみ）
3. `test/` 配下のファイルを変更しない
4. 関数に 1〜3 行の JSDoc コメントがある

## 仕様の詳細

- 小文字化する
- アクセント付き文字は基底文字に落とす（`Café` → `cafe`）
- 英数字以外の連続は 1 つのハイフンにまとめる
- 先頭と末尾のハイフンは取り除く
- 空文字列は空文字列を返す

## やってはいけないこと

- `test/` の変更、削除
- ネットワークアクセス
- `src/` 以外への新規ファイル作成（進捗メモへの追記は除く）
